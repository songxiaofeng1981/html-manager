# 安装 Manager

[English](INSTALL.md) | **中文**

这份说明不需要任何编程基础。按顺序做就行，大约 5 分钟。

**需要：** 一台 macOS 13（Ventura）或更新系统的 Mac，以及 Google Chrome。
Microsoft Edge、Brave、Arc、Vivaldi 也可以用，步骤相同。

---

## 第 1 步：下载

1. 打开[最新版本页面](https://github.com/songxiaofeng1981/html-manager/releases/latest)。
2. 在 **Assets** 下面点 **`html-manager-v1.6.0.zip`**（版本号可能更高）。
   不要点“Source code”，那是源代码，需要开发工具才能用。
3. 打开“下载”文件夹，双击这个 zip 文件，会出现一个叫 `html-manager-v1.6.0` 的文件夹。

## 第 2 步：运行安装程序

1. 打开“终端”：按 `⌘ 空格`，输入 `终端`（或 `Terminal`），按回车。
2. 在终端窗口里输入 `bash`，后面加**一个空格**。先不要按回车。
3. 把 `html-manager-v1.6.0` 文件夹里的 **`install.sh`** 拖进终端窗口。
   这一行会变成类似 `bash /Users/你的用户名/Downloads/html-manager-v1.6.0/install.sh` 的样子。
4. 按回车。

几秒钟后会显示 **“完成！”**，并自动打开 Chrome 的扩展程序页面。

> **为什么用终端，而不是双击？** macOS 会拦截从网上下载的脚本，不让双击运行，绕过去的设置藏得很深。
> 从终端启动就不会遇到这个拦截。安装程序只把文件复制到你自己的用户文件夹，不需要输入密码。

## 第 3 步：把插件加到 Chrome

安装程序已经帮你打开了 `chrome://extensions`。如果没有，在 Chrome 地址栏输入 `chrome://extensions` 并回车。

1. 打开右上角的 **“开发者模式”** 开关。
2. 点左上角的 **“加载已解压的扩展程序”**。
3. 会弹出一个选择文件夹的窗口。按 `⌘ Shift G`，再按 `⌘ V`（安装程序已经帮你复制好了文件夹路径），然后按回车。
4. 点 **“选择”**。
5. 在 Manager 卡片上点 **“详情”**，打开 **“允许访问文件网址”**。这样才能在新标签页打开你的 HTML、显示缩略图。
6. 点 Chrome 工具栏上的拼图图标，再点 **Manager** 旁边的图钉，把它固定到工具栏。

> 因为这个插件还没有上架 Chrome 应用商店，所以需要打开开发者模式。
> Chrome 偶尔会提醒你装了开发者模式的插件，这是正常的。

## 第 4 步：新建资料库

1. 点工具栏里的 **Manager** 图标。
2. 第一次打开时会显示 **“新建资料库”**。点 **“新建资料库”**，Manager 会在“下载”文件夹里创建 `Manager_Files` 文件夹和存放索引的隐藏文件夹 `.manager`，不改动其他文件。
   - 想把资料库放在别处（比如移动硬盘）？先点 **“设置资料库位置…”**，填好文件夹路径再新建。
3. 如果 macOS 问 *“Manager 本机助手”想要访问“下载”文件夹中的文件*，点 **“允许”**。

## 第 5 步：收录第一批 HTML

1. 点侧边栏的 **“收录新 HTML”**。Manager 会列出“下载”里还没收录的 HTML。
2. 勾选要收录的文件。每篇都核对一下 **分类** 和 **2～4 个标签**（点“+ 标签”从词表里选）。
3. 点 **“归档并收录”**。文件会移到 `Manager_Files`，并生成缩略图。

完成。🎉 现在可以删掉下载的 `html-manager-v1.6.0` 文件夹和 zip 文件了。

---

## 把资料库放到移动硬盘

1. 插上硬盘，在访达里把整个资料库（`Manager_Files`，以及隐藏的 `.manager` 和 `.thumbs`；按 `⌘ ⇧ .` 显示隐藏文件夹）拖到硬盘上，例如 `/Volumes/我的硬盘/`。
   忘了拷 `.manager`？Manager 会从 `Manager_Files` 里的文件重建索引。
2. 在 Manager 侧边栏底部点文件夹按钮 **“资料库位置”**。
3. **资料库** 填硬盘上的文件夹，例如 `/Volumes/我的硬盘`。**收件文件夹** 留空（就是“下载”）。
   不知道路径？在访达里选中那个文件夹，按 `⌥ ⌘ C` 就能复制路径。
4. 点 **“保存”**。如果 macOS 问能否访问可移除的宗卷，点 **“允许”**。

以后新下载的 HTML 仍在“下载”里，收录时会被移到硬盘上的资料库。
硬盘没插时，Manager 会显示“资料库暂时无法访问”，插上后点“重试”即可。

## 更新到新版本

1. 下载新的 zip 并解压（第 1 步）。
2. 再运行一次 `bash install.sh`（第 2 步）。
3. 在 `chrome://extensions` 里点 Manager 卡片上的刷新图标（↻）。

资料库和资料库位置设置都会保留。

**从 1.5 或更早的版本升级：** 1.6 第一次打开时，会把索引从 `Manager.html` 搬进隐藏的 `.manager/index.json`，
并把旧文件改名为 `Manager-旧索引.html`（不会删除；确认一切正常后可以自己扔掉）。
请先更新本机助手（第 2 步）再刷新插件：旧的本机助手读不了新索引。

## 遇到问题？

| 你看到的情况 | 怎么办 |
|---|---|
| 页面显示 **“本机助手未连接”** | 重新做第 2 步。然后确认 `chrome://extensions` 里 Manager 卡片上显示的 ID 是 `jpencbldoocakpdbgolffgemckpimnph`。 |
| 页面显示 **“本机助手需要更新”** | 用新版本的文件夹重新做第 2 步，再在 `chrome://extensions` 点刷新。 |
| 页面显示 **“无法读取 Manager 索引”** | 点 **“重建索引…”**。资料和它们的信息都在 HTML 文件里，不会丢；原来的文件会保留。 |
| 页面显示 **“无法访问资料文件夹”** | 打开 **“系统设置”→“隐私与安全性”→“文件和文件夹”**，找到 **Manager 本机助手**，打开 **“下载”文件夹**（和 **“可移除的宗卷”**）开关，然后点 **“重试”**。 |
| 页面显示 **“资料库暂时无法访问”** | 资料库所在的硬盘没插上，或文件夹被改名了。插上硬盘点“重试”，或在“资料库位置”里改成正确的文件夹。 |
| 卡片没有缩略图，或打不开文件 | 在 `chrome://extensions` 的 Manager **“详情”** 里打开 **“允许访问文件网址”**。 |
| 收录时提示 **缩略图没有生成** | 在访达里选中那个 HTML，按空格看能不能预览。能预览就再试一次；不能的话，这个文件可能已损坏。 |
| 终端显示 `No such file or directory` | 确认 `bash` 后面有一个空格，并且拖进去的是 `install.sh` 文件，而不是整个文件夹。 |
| 终端显示“这个文件夹里没有现成的本机助手” | 你下载的是“Source code”，不是发布版 zip。回到第 1 步重新下载。 |
| Chrome 提示 **清单文件缺失或不可读** | 第 3 步选错了文件夹。请选择 `~/Applications/Manager HTML/extension`（按 `⌘ Shift G` 后粘贴）。 |

想不经过 Chrome 检查本机助手，可以在终端运行：

```bash
bash "$HOME/Library/Application Support/Manager HTML/selftest.sh"
```

它会显示资料库在哪里、找到了多少篇资料、有多少待收录。

还是解决不了？请[提一个 issue](https://github.com/songxiaofeng1981/html-manager/issues/new/choose)，写上你的 macOS 版本和看到的情况。中文英文都可以。

## 卸载

1. 打开终端，粘贴下面这一行并按回车。它会删除本机助手、设置和插件文件，**不会动你的资料库和 HTML 文件**。
   ```bash
   bash "$HOME/Library/Application Support/Manager HTML/uninstall.sh"
   ```
2. 在 `chrome://extensions` 里点 Manager 的 **“移除”**。
